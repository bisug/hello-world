# Hello World in Many Languages

This is a learning reference for `Hello, World!` in many programming languages. Open a language file to read a short note, a run command, and an official link in its comments.

## Systems

- [C](c/) [compiled] - small compiled language used for systems code and embedded programs. [docs](https://www.open-std.org/jtc1/sc22/wg14/)
- [C++](cpp/) [compiled] - adds classes and templates to C and is used where control and speed matter. [docs](https://isocpp.org/)
- [Rust](rust/) [compiled] - compiled language that prevents memory errors without a garbage collector. [docs](https://www.rust-lang.org/)
- [Go](go/) [compiled] - simple compiled language built for network services and tools. [docs](https://go.dev/)
- [Goose](goose/) [compiled] - memory-safe systems language with no heap allocator or garbage collector. [docs](https://aardappel.github.io/goose/)
- [Zig](zig/) [compiled] - low level language made to replace C with explicit control over memory. [docs](https://ziglang.org/)
- [Nim](nim/) [compiled] - compiled language with Python like syntax. [docs](https://nim-lang.org/)
- [D](d/) [compiled] - compiled language that keeps C compatibility while adding higher level features. [docs](https://dlang.org/)
- [Ada](ada/) [compiled] - strict language used in avionics and other safety critical systems. [docs](https://www.adaic.org/)
- [Fortran](fortran/) [compiled] - built for numerical work and still runs in scientific codes. [docs](https://fortran-lang.org/)
- [Pascal](pascal/) [compiled] - teaching language with strong types and structured code. [docs](https://www.freepascal.org/)
- [COBOL](cobol/) [compiled] - handles business records and still runs in banking systems. [docs](https://www.gnu.org/software/gnucobol/)
- [Assembly](assembly/) [compiled] - speaks directly to the CPU and is used when every instruction counts. [docs](https://www.nasm.us/)
- [Odin](odin/) [compiled] - C style language built for games and clear data layouts. [docs](https://odin-lang.org/)
- [V](vlang/) [compiled] - small compiled language made for fast builds and simple syntax. [docs](https://vlang.io/)
- [C3](c3/) [compiled] - keeps C syntax while adding safer error handling and modules. [docs](https://c3-lang.org/)
- [Hare](hare/) [compiled] - small systems language with a short specification. [docs](https://harelang.org/)
- [Beef](beef/) [compiled] - systems language focused on games and manual memory control. [docs](https://www.beeflang.org/)
- [Hylo](hylo/) [compiled] - safe systems language built from research on value semantics. [docs](https://www.hylo-lang.org/)
- [Vale](vale/) [compiled] - explores memory safety without a borrow checker. [docs](https://vale.dev/)
- [Carbon](carbon/) [compiled] - experiment in a successor to C++. [docs](https://github.com/carbon-language/carbon-lang)
- [Mojo](mojo/) [compiled] - extends Python with types for fast machine learning code. [docs](https://www.modular.com/mojo)
- [Crystal](crystal/) [compiled] - has Ruby syntax and compiles to native code. [docs](https://crystal-lang.org/)
- [Vala](vala/) [compiled] - compiles to C and is used for GNOME applications. [docs](https://wiki.gnome.org/Projects/Vala)
- [Haxe](haxe/) [transpiled] - compiles one codebase to many targets including JavaScript. [docs](https://haxe.org/)
- [Objective-C](objectivec/) [compiled] - adds objects to C and powers much of Apple's older code. [docs](https://developer.apple.com/library/archive/navigation/)

- [ATS](ats/) [compiled] - systems language with dependent types for proving program properties. [docs](https://www.ats-lang.org/)
- [Self](self/) [jit] - prototype based language where everything is an object. [docs](https://selflanguage.org/)
- [REBOL](rebol/) [interpreted] - data oriented language made for network scripts. [docs](https://www.rebol.com/)
- [Red](red/) [interpreted] - language built for scripting and distributed systems. [docs](https://www.red-lang.org/)
## JVM and .NET

- [Java](java/) [jit] - runs on the JVM and is used for large server applications. [docs](https://www.oracle.com/java/)
- [Kotlin](kotlin/) [jit] - shorter JVM language used for servers and Android apps. [docs](https://kotlinlang.org/)
- [Scala](scala/) [jit] - mixes object oriented and functional code on the JVM. [docs](https://www.scala-lang.org/)
- [Groovy](groovy/) [jit] - JVM language with a light syntax used in build scripts. [docs](https://groovy-lang.org/)
- [Clojure](clojure/) [jit] - Lisp on the JVM built around immutable data. [docs](https://clojure.org/)
- [Ceylon](ceylon/) [compiled] - JVM language with a strong type system. [docs](https://ceylon-lang.org/)
- [C#](csharp/) [jit] - the main language of the .NET platform. [docs](https://learn.microsoft.com/en-us/dotnet/csharp/)
- [F#](fsharp/) [jit] - functional language on .NET. [docs](https://learn.microsoft.com/en-us/dotnet/fsharp/)
- [VB.NET](vbnet/) [jit] - the Visual Basic language for .NET. [docs](https://learn.microsoft.com/en-us/dotnet/visual-basic/)

## Scripting

- [Python](python/) [interpreted] - general purpose language used for scripts, web back ends, and data work. [docs](https://www.python.org/)
- [PHP](php/) [interpreted] - server language that powers much of the web. [docs](https://www.php.net/)
- [Ruby](ruby/) [interpreted] - scripting language valued for readable code. [docs](https://www.ruby-lang.org/)
- [Perl](perl/) [interpreted] - text processing language used in system scripts. [docs](https://www.perl.org/)
- [Lua](lua/) [interpreted] - small scripting language often embedded in games. [docs](https://www.lua.org/)
- [Tcl](tcl/) [interpreted] - scripting language used for tools and testing. [docs](https://www.tcl.tk/)
- [AWK](awk/) [interpreted] - processes text files one line at a time. [docs](https://www.gnu.org/software/gawk/)
- [sed](sed/) [interpreted] - stream editor for filtering and changing text. [docs](https://www.gnu.org/software/sed/)
- [Nix](nix/) [interpreted] - language for describing packages and system builds. [docs](https://nixos.org/)
- [Raku](raku/) [jit] - language with many ways to express the same idea. [docs](https://raku.org/)
- [Julia](julia/) [jit] - built for numerical work and compiles at run time. [docs](https://julialang.org/)
- [GNUplot](gnuplot/) [interpreted] - scripting language for plotting data and functions. [docs](http://www.gnuplot.info/)

- [Ksh](ksh/) [interpreted] - the Korn shell, a Unix shell with strong scripting features. [docs](http://www.kornshell.com/)
- [Nushell](nushell/) [interpreted] - shell that works with structured data instead of plain text. [docs](https://www.nushell.sh/)
- [Elvish](elvish/) [interpreted] - shell with a programming language for interactive work. [docs](https://elv.sh/)

- [xonsh](xonsh/) [interpreted] - shell that mixes Python with shell commands. [docs](https://xon.sh/)

## Functional

- [OCaml](ocaml/) [compiled] - functional language with a strong static type system. [docs](https://ocaml.org/)
- [Common Lisp](common-lisp/) [jit] - large Lisp dialect used for long lived systems. [docs](https://common-lisp.net/)
- [Scheme](scheme/) [interpreted] - small Lisp with a minimal core. [docs](https://www.scheme.org/)
- [Racket](racket/) [jit] - Lisp used for teaching and language building. [docs](https://racket-lang.org/)
- [Erlang](erlang/) [jit] - built for concurrent systems that must stay up. [docs](https://www.erlang.org/)
- [Elixir](elixir/) [jit] - runs on the Erlang VM with a Ruby like syntax. [docs](https://elixir-lang.org/)
- [Fennel](fennel/) [transpiled] - Lisp that compiles to Lua. [docs](https://fennel-lang.org/)
- [Janet](janet/) [interpreted] - small Lisp for scripting and embedded use. [docs](https://janet-lang.org/)
- [Roc](roc/) [compiled] - functional language focused on data and interop. [docs](https://roc-lang.org/)
- [Unison](unison/) [compiled] - stores code by its content instead of by file name. [docs](https://www.unison-lang.org/)
- [Gleam](gleam/) [transpiled] - typed functional language for the Erlang VM and JavaScript. [docs](https://gleam.run/)
- [Koka](koka/) [compiled] - tracks effects in the type system. [docs](https://koka-lang.github.io/)

- [Standard ML](sml/) [compiled] - functional language with a precise module system. [docs](https://www.smlnj.org/)

- [Elm](elm/) [transpiled] - functional language that compiles to JavaScript for browser apps. [docs](https://elm-lang.org/)
- [PureScript](purescript/) [transpiled] - typed functional language that compiles to JavaScript. [docs](https://www.purescript.org/)
- [ReScript](rescript/) [transpiled] - typed language that compiles to JavaScript. [docs](https://rescript-lang.org/)
- [Flix](flix/) [compiled] - functional and logic language with effect types. [docs](https://flix.dev/)
- [Carp](carp/) [compiled] - Lisp that compiles to C for systems code. [docs](https://carp-lang.org/)

- [SQL](sql/) [query] - queries data in relational databases. [docs](https://www.sqlite.org/)
- [XQuery](xquery/) [query] - queries XML documents. [docs](https://www.w3.org/XML/Query/)

- [Kap](kap/) [interpreted] - modern array language in the APL family. [docs](https://github.com/kapitaali/kap)
- [XSLT](xslt/) [query] - language for transforming XML documents. [docs](https://www.w3.org/TR/xslt/)
