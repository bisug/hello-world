# Hello World in Many Languages

This is a learning reference for `Hello, World!` in many programming languages. Open a language file to read a short note, a run command, and an official link in its comments.

## Systems

- [C](c/) - small compiled language used for systems code and embedded programs.
- [C++](cpp/) - adds classes and templates to C and is used where control and speed matter.
- [Rust](rust/) - compiled language that prevents memory errors without a garbage collector.
- [Go](go/) - simple compiled language built for network services and tools.
- [Goose](goose/) - memory-safe systems language with no heap allocator or garbage collector.
- [Zig](zig/) - low level language made to replace C with explicit control over memory.
- [Nim](nim/) - compiled language with Python like syntax.
- [D](d/) - compiled language that keeps C compatibility while adding higher level features.
- [Ada](ada/) - strict language used in avionics and other safety critical systems.
- [Fortran](fortran/) - built for numerical work and still runs in scientific codes.
- [Pascal](pascal/) - teaching language with strong types and structured code.
- [COBOL](cobol/) - handles business records and still runs in banking systems.
- [Assembly](assembly/) - speaks directly to the CPU and is used when every instruction counts.
- [Odin](odin/) - C style language built for games and clear data layouts.
- [V](vlang/) - small compiled language made for fast builds and simple syntax.
- [C3](c3/) - keeps C syntax while adding safer error handling and modules.
- [Hare](hare/) - small systems language with a short specification.
- [Beef](beef/) - systems language focused on games and manual memory control.
- [Hylo](hylo/) - safe systems language built from research on value semantics.
- [Vale](vale/) - explores memory safety without a borrow checker.
- [Carbon](carbon/) - experiment in a successor to C++.
- [Mojo](mojo/) - extends Python with types for fast machine learning code.
- [Crystal](crystal/) - has Ruby syntax and compiles to native code.
- [Vala](vala/) - compiles to C and is used for GNOME applications.
- [Haxe](haxe/) - compiles one codebase to many targets including JavaScript.
- [Objective-C](objectivec/) - adds objects to C and powers much of Apple's older code.

- [ATS](ats/) - systems language with dependent types for proving program properties.
- [Self](self/) - prototype based language where everything is an object.
- [REBOL](rebol/) - data oriented language made for network scripts.
- [Red](red/) - language built for scripting and distributed systems.
## JVM and .NET

- [Java](java/) - runs on the JVM and is used for large server applications.
- [Kotlin](kotlin/) - shorter JVM language used for servers and Android apps.
- [Scala](scala/) - mixes object oriented and functional code on the JVM.
- [Groovy](groovy/) - JVM language with a light syntax used in build scripts.
- [Clojure](clojure/) - Lisp on the JVM built around immutable data.
- [Ceylon](ceylon/) - JVM language with a strong type system.
- [C#](csharp/) - the main language of the .NET platform.
- [F#](fsharp/) - functional language on .NET.
- [VB.NET](vbnet/) - the Visual Basic language for .NET.

## Scripting and web

- [Python](python/) - general purpose language used for scripts, web back ends, and data work.
- [PHP](php/) - server language that powers much of the web.
- [Ruby](ruby/) - scripting language valued for readable code.
- [Perl](perl/) - text processing language used in system scripts.
- [Lua](lua/) - small scripting language often embedded in games.
- [Tcl](tcl/) - scripting language used for tools and testing.
- [AWK](awk/) - processes text files one line at a time.
- [sed](sed/) - stream editor for filtering and changing text.
- [Bash](bash/) - the shell used on most Linux systems.
- [Zsh](zsh/) - shell with stronger completion and prompts than Bash.
- [Fish](fish/) - shell built for clear syntax and good defaults.
- [PowerShell](powershell/) - shell and scripting language from Microsoft.
- [Batch](batch/) - the command script language of Windows.
- [Nix](nix/) - language for describing packages and system builds.
- [Raku](raku/) - language with many ways to express the same idea.
- [Julia](julia/) - built for numerical work and compiles at run time.
- [Dart](dart/) - used for Flutter apps and web code.
- [JavaScript](javascript/) - the main language of the browser and runs on servers too.
- [TypeScript](typescript/) - adds static types to JavaScript.
- [CoffeeScript](coffeescript/) - compiles short syntax into JavaScript.
- [WebAssembly text](wat/) - text form of WebAssembly modules.

- [Tcsh](tcsh/) - Unix shell with C like syntax and command completion.
- [Ksh](ksh/) - the Korn shell, a Unix shell with strong scripting features.
- [Nushell](nushell/) - shell that works with structured data instead of plain text.
- [Elvish](elvish/) - shell with a programming language for interactive work.
- [Oil shell](oil/) - Unix shell with a typed language called YSH.
- [xonsh](xonsh/) - shell that mixes Python with shell commands.
- [GNUplot](gnuplot/) - scripting language for plotting data and functions.
- [GraphQL](graphql/) - query language for reading data from APIs.
## Functional

- [Haskell](haskell/) - pure functional language with lazy evaluation.
- [OCaml](ocaml/) - functional language with a strong static type system.
- [Common Lisp](common-lisp/) - large Lisp dialect used for long lived systems.
- [Scheme](scheme/) - small Lisp with a minimal core.
- [Racket](racket/) - Lisp used for teaching and language building.
- [Erlang](erlang/) - built for concurrent systems that must stay up.
- [Elixir](elixir/) - runs on the Erlang VM with a Ruby like syntax.
- [Fennel](fennel/) - Lisp that compiles to Lua.
- [Janet](janet/) - small Lisp for scripting and embedded use.
- [Roc](roc/) - functional language focused on data and interop.
- [Unison](unison/) - stores code by its content instead of by file name.
- [Gleam](gleam/) - typed functional language for the Erlang VM and JavaScript.
- [Koka](koka/) - tracks effects in the type system.
- [Effekt](effekt/) - functional language with effect handlers.
- [Idris](idris/) - uses dependent types to prove facts about code.
- [Agda](agda/) - proof assistant built on dependent types.
- [Standard ML](sml/) - functional language with a precise module system.

- [Elm](elm/) - functional language that compiles to JavaScript for browser apps.
- [PureScript](purescript/) - typed functional language that compiles to JavaScript.
- [ReScript](rescript/) - typed language that compiles to JavaScript.
- [Flix](flix/) - functional and logic language with effect types.
- [Carp](carp/) - Lisp that compiles to C for systems code.
## Data and logic

- [Mercury](mercury/) - logic language with static types and modes.
- [R](r/) - language for statistics and data analysis.
- [MATLAB](matlab/) - used for matrix math and engineering work.
- [Octave](octave/) - open source MATLAB like language.
- [SAS](sas/) - used for statistics and data in large organizations.
- [Stata](stata/) - used for econometrics and panel data.
- [Wolfram Language](wolfram/) - symbolic language built for computation and notebooks.
- [APL](apl/) - uses short symbols to work on whole arrays at once.
- [J](j/) - array language derived from APL.
- [K](k/) - terse array language used for fast data work.
- [Q](q/) - database language built on K.
- [BQN](bqn/) - modern array language.
- [Uiua](uiua/) - array language built around a stack.
- [Prolog](prolog/) - solves goals by matching rules and facts.
- [Datalog](datalog/) - declarative language for logic over relations.
- [SQL](sql/) - queries data in relational databases.
- [XQuery](xquery/) - queries XML documents.

- [Kap](kap/) - modern array language in the APL family.
- [XSLT](xslt/) - language for transforming XML documents.
- [XPath](xpath/) - expression language for selecting parts of an XML document.
## Mobile

- [Swift](swift/) - used for iOS apps and server code.

## Blockchain

- [Solidity](solidity/) - writes smart contracts for Ethereum.
- [Vyper](vyper/) - Python like language for Ethereum contracts.
- [Move](move/) - language for digital assets on blockchains.
- [Cairo](cairo/) - writes programs with provable execution for Starknet.
- [Noir](noir/) - language for zero knowledge circuits.
- [Circom](circom/) - describes arithmetic circuits for zero knowledge proofs.
- [Leo](leo/) - language for private applications on Aleo.
- [Tact](tact/) - language for TON smart contracts.
- [Clarity](clarity/) - decidable language for Stacks contracts.
- [Michelson](michelson/) - the contract language of Tezos.

- [Plutus](plutus/) - Haskell based language for Cardano smart contracts.
- [Marlowe](marlowe/) - domain language for financial contracts on Cardano.
- [Fe](fe/) - experimental smart contract language for Ethereum.
## Hardware and shaders

- [Verilog](verilog/) - describes hardware at the register transfer level.
- [VHDL](vhdl/) - hardware description language used in chip design.
- [SystemVerilog](systemverilog/) - extends Verilog for verification and design.
- [Chisel](chisel/) - builds hardware using Scala code.
- [GLSL](glsl/) - writes shaders for OpenGL and Vulkan.
- [HLSL](hlsl/) - writes shaders for DirectX.
- [WGSL](wgsl/) - the shader language of WebGPU.
- [CUDA](cuda/) - runs C like code on NVIDIA GPUs.
- [OpenCL](opencl/) - runs code across CPUs, GPUs, and other devices.

## Other

- [TADS](tads/) - language for writing text adventures.
- [Inform](inform/) - language for writing interactive fiction.
- [Q#](qsharp/) - language for writing quantum computing programs.
- [Smalltalk](smalltalk/) - object oriented language built around messages.
- [Forth](forth/) - builds programs from small stack based words.
- [PostScript](postscript/) - stack language used for page descriptions.
- [Io](io/) - prototype based language built around message passing.
