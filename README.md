# Hello World in Many Languages

This is a learning reference for `Hello, World!` in many programming languages. Open a language file to read a short note, a run command, and an official link in its comments.

## Systems

- [C](c/) - small compiled language used for systems code and embedded programs. [docs](https://www.open-std.org/jtc1/sc22/wg14/)
- [C++](cpp/) - adds classes and templates to C and is used where control and speed matter. [docs](https://isocpp.org/)
- [Rust](rust/) - compiled language that prevents memory errors without a garbage collector. [docs](https://www.rust-lang.org/)
- [Go](go/) - simple compiled language built for network services and tools. [docs](https://go.dev/)
- [Goose](goose/) - memory-safe systems language with no heap allocator or garbage collector. [docs](https://aardappel.github.io/goose/)
- [Zig](zig/) - low level language made to replace C with explicit control over memory. [docs](https://ziglang.org/)
- [Nim](nim/) - compiled language with Python like syntax. [docs](https://nim-lang.org/)
- [D](d/) - compiled language that keeps C compatibility while adding higher level features. [docs](https://dlang.org/)
- [Ada](ada/) - strict language used in avionics and other safety critical systems. [docs](https://www.adaic.org/)
- [Fortran](fortran/) - built for numerical work and still runs in scientific codes. [docs](https://fortran-lang.org/)
- [Pascal](pascal/) - teaching language with strong types and structured code. [docs](https://www.freepascal.org/)
- [COBOL](cobol/) - handles business records and still runs in banking systems. [docs](https://www.gnu.org/software/gnucobol/)
- [Assembly](assembly/) - speaks directly to the CPU and is used when every instruction counts. [docs](https://www.nasm.us/)
- [Odin](odin/) - C style language built for games and clear data layouts. [docs](https://odin-lang.org/)
- [V](vlang/) - small compiled language made for fast builds and simple syntax. [docs](https://vlang.io/)
- [C3](c3/) - keeps C syntax while adding safer error handling and modules. [docs](https://c3-lang.org/)
- [Hare](hare/) - small systems language with a short specification. [docs](https://harelang.org/)
- [Beef](beef/) - systems language focused on games and manual memory control. [docs](https://www.beeflang.org/)
- [Hylo](hylo/) - safe systems language built from research on value semantics. [docs](https://www.hylo-lang.org/)
- [Vale](vale/) - explores memory safety without a borrow checker. [docs](https://vale.dev/)
- [Carbon](carbon/) - experiment in a successor to C++. [docs](https://github.com/carbon-language/carbon-lang)
- [Mojo](mojo/) - extends Python with types for fast machine learning code. [docs](https://www.modular.com/mojo)
- [Crystal](crystal/) - has Ruby syntax and compiles to native code. [docs](https://crystal-lang.org/)
- [Vala](vala/) - compiles to C and is used for GNOME applications. [docs](https://wiki.gnome.org/Projects/Vala)
- [Haxe](haxe/) - compiles one codebase to many targets including JavaScript. [docs](https://haxe.org/)
- [Objective-C](objectivec/) - adds objects to C and powers much of Apple's older code. [docs](https://developer.apple.com/library/archive/navigation/)

- [ATS](ats/) - systems language with dependent types for proving program properties. [docs](https://www.ats-lang.org/)
- [Self](self/) - prototype based language where everything is an object. [docs](https://selflanguage.org/)
- [REBOL](rebol/) - data oriented language made for network scripts. [docs](https://www.rebol.com/)
- [Red](red/) - language built for scripting and distributed systems. [docs](https://www.red-lang.org/)
## JVM and .NET

- [Java](java/) - runs on the JVM and is used for large server applications. [docs](https://www.oracle.com/java/)
- [Kotlin](kotlin/) - shorter JVM language used for servers and Android apps. [docs](https://kotlinlang.org/)
- [Scala](scala/) - mixes object oriented and functional code on the JVM. [docs](https://www.scala-lang.org/)
- [Groovy](groovy/) - JVM language with a light syntax used in build scripts. [docs](https://groovy-lang.org/)
- [Clojure](clojure/) - Lisp on the JVM built around immutable data. [docs](https://clojure.org/)
- [Ceylon](ceylon/) - JVM language with a strong type system. [docs](https://ceylon-lang.org/)
- [C#](csharp/) - the main language of the .NET platform. [docs](https://learn.microsoft.com/en-us/dotnet/csharp/)
- [F#](fsharp/) - functional language on .NET. [docs](https://learn.microsoft.com/en-us/dotnet/fsharp/)
- [VB.NET](vbnet/) - the Visual Basic language for .NET. [docs](https://learn.microsoft.com/en-us/dotnet/visual-basic/)

## Scripting

- [Python](python/) - general purpose language used for scripts, web back ends, and data work. [docs](https://www.python.org/)
- [PHP](php/) - server language that powers much of the web. [docs](https://www.php.net/)
- [Ruby](ruby/) - scripting language valued for readable code. [docs](https://www.ruby-lang.org/)
- [Perl](perl/) - text processing language used in system scripts. [docs](https://www.perl.org/)
- [Lua](lua/) - small scripting language often embedded in games. [docs](https://www.lua.org/)
- [Tcl](tcl/) - scripting language used for tools and testing. [docs](https://www.tcl.tk/)
- [AWK](awk/) - processes text files one line at a time. [docs](https://www.gnu.org/software/gawk/)
- [sed](sed/) - stream editor for filtering and changing text. [docs](https://www.gnu.org/software/sed/)
- [Nix](nix/) - language for describing packages and system builds. [docs](https://nixos.org/)
- [Raku](raku/) - language with many ways to express the same idea. [docs](https://raku.org/)
- [Julia](julia/) - built for numerical work and compiles at run time. [docs](https://julialang.org/)
- [GNUplot](gnuplot/) - scripting language for plotting data and functions. [docs](http://www.gnuplot.info/)

## Shells

- [Bash](bash/) - the shell used on most Linux systems. [docs](https://www.gnu.org/software/bash/)
- [Zsh](zsh/) - shell with stronger completion and prompts than Bash. [docs](https://www.zsh.org/)
- [Fish](fish/) - shell built for clear syntax and good defaults. [docs](https://fishshell.com/)
- [PowerShell](powershell/) - shell and scripting language from Microsoft. [docs](https://learn.microsoft.com/en-us/powershell/)
- [Batch](batch/) - the command script language of Windows. [docs](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands)
- [Tcsh](tcsh/) - Unix shell with C like syntax and command completion. [docs](https://www.tcsh.org/)
- [Ksh](ksh/) - the Korn shell, a Unix shell with strong scripting features. [docs](http://www.kornshell.com/)
- [Nushell](nushell/) - shell that works with structured data instead of plain text. [docs](https://www.nushell.sh/)
- [Elvish](elvish/) - shell with a programming language for interactive work. [docs](https://elv.sh/)
- [Oil shell](oil/) - Unix shell with a typed language called YSH. [docs](https://www.oilshell.org/)
- [xonsh](xonsh/) - shell that mixes Python with shell commands. [docs](https://xon.sh/)

## Functional

- [Haskell](haskell/) - pure functional language with lazy evaluation. [docs](https://www.haskell.org/)
- [OCaml](ocaml/) - functional language with a strong static type system. [docs](https://ocaml.org/)
- [Common Lisp](common-lisp/) - large Lisp dialect used for long lived systems. [docs](https://common-lisp.net/)
- [Scheme](scheme/) - small Lisp with a minimal core. [docs](https://www.scheme.org/)
- [Racket](racket/) - Lisp used for teaching and language building. [docs](https://racket-lang.org/)
- [Erlang](erlang/) - built for concurrent systems that must stay up. [docs](https://www.erlang.org/)
- [Elixir](elixir/) - runs on the Erlang VM with a Ruby like syntax. [docs](https://elixir-lang.org/)
- [Fennel](fennel/) - Lisp that compiles to Lua. [docs](https://fennel-lang.org/)
- [Janet](janet/) - small Lisp for scripting and embedded use. [docs](https://janet-lang.org/)
- [Roc](roc/) - functional language focused on data and interop. [docs](https://roc-lang.org/)
- [Unison](unison/) - stores code by its content instead of by file name. [docs](https://www.unison-lang.org/)
- [Gleam](gleam/) - typed functional language for the Erlang VM and JavaScript. [docs](https://gleam.run/)
- [Koka](koka/) - tracks effects in the type system. [docs](https://koka-lang.github.io/)
- [Effekt](effekt/) - functional language with effect handlers. [docs](https://effekt-lang.org/)
- [Idris](idris/) - uses dependent types to prove facts about code. [docs](https://www.idris-lang.org/)
- [Agda](agda/) - proof assistant built on dependent types. [docs](https://agda.readthedocs.io/)
- [Standard ML](sml/) - functional language with a precise module system. [docs](https://www.smlnj.org/)

- [Elm](elm/) - functional language that compiles to JavaScript for browser apps. [docs](https://elm-lang.org/)
- [PureScript](purescript/) - typed functional language that compiles to JavaScript. [docs](https://www.purescript.org/)
- [ReScript](rescript/) - typed language that compiles to JavaScript. [docs](https://rescript-lang.org/)
- [Flix](flix/) - functional and logic language with effect types. [docs](https://flix.dev/)
- [Carp](carp/) - Lisp that compiles to C for systems code. [docs](https://carp-lang.org/)
## Data and logic

- [Mercury](mercury/) - logic language with static types and modes. [docs](https://mercurylang.org/)
- [R](r/) - language for statistics and data analysis. [docs](https://www.r-project.org/)
- [MATLAB](matlab/) - used for matrix math and engineering work. [docs](https://www.mathworks.com/products/matlab.html)

- [Stata](stata/) - used for econometrics and panel data. [docs](https://www.stata.com/)

- [SQL](sql/) - queries data in relational databases. [docs](https://www.sqlite.org/)
- [XQuery](xquery/) - queries XML documents. [docs](https://www.w3.org/XML/Query/)

- [Kap](kap/) - modern array language in the APL family. [docs](https://github.com/kapitaali/kap)
- [XSLT](xslt/) - language for transforming XML documents. [docs](https://www.w3.org/TR/xslt/)
- [XPath](xpath/) - expression language for selecting parts of an XML document. [docs](https://www.w3.org/TR/xpath-31/)

- [Chisel](chisel/) - builds hardware using Scala code. [docs](https://www.chisel-lang.org/)
- [GLSL](glsl/) - writes shaders for OpenGL and Vulkan. [docs](https://www.khronos.org/opengl/wiki/OpenGL_Shading_Language)

- [WGSL](wgsl/) - the shader language of WebGPU. [docs](https://www.w3.org/TR/WGSL/)
- [CUDA](cuda/) - runs C like code on NVIDIA GPUs. [docs](https://developer.nvidia.com/cuda-zone)
- [OpenCL](opencl/) - runs code across CPUs, GPUs, and other devices. [docs](https://www.khronos.org/opencl/)
